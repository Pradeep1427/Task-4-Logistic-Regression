# Task 4 - Classification with Logistic Regression

## Internship Task

This project was completed as part of the AI & ML Internship.

## Objective

The objective of this task is to build a binary classification model using Logistic Regression.

## Dataset

The Breast Cancer Wisconsin dataset was used for binary classification.

## Tools and Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Steps Performed

1. Loaded the dataset.
2. Explored the dataset.
3. Split the dataset into training and testing sets.
4. Standardized the features.
5. Trained a Logistic Regression model.
6. Generated predictions.
7. Evaluated the model using a confusion matrix.
8. Calculated precision and recall.
9. Calculated ROC-AUC.
10. Plotted the ROC curve.
11. Visualized the sigmoid function.
12. Tested different classification thresholds.

## Evaluation Metrics

The model was evaluated using:

- Confusion Matrix
- Precision
- Recall
- ROC-AUC

## Conclusion

A Logistic Regression model was successfully developed for binary classification. The model was evaluated using multiple classification metrics, and threshold tuning was performed to understand the trade-off between precision and recall.
